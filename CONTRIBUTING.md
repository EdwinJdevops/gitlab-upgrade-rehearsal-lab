# Contributing

This repository is evidence-driven. A feature request is not enough to widen scope.

Contributions should include:

- the failure mode or research question;
- an authoritative or reproducible source;
- why current GitLab tooling does not already solve it;
- a deterministic fixture or reproduction when possible;
- the expected evidence status;
- security/fidelity impact.

Deterministic GitLab upgrade knowledge should normally be contributed upstream rather than copied into this repository.
